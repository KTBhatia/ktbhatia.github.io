I gave myself a week to build something real in a language I'd never touched. Not a tutorial project — an actual tool I'd use afterward.

## What I built

A small CLI that reformats my export files before they hit a spreadsheet. Low stakes, real use, done in a language whose syntax I was still looking up on day three.

## What stuck

- The standard library's shape tells you what the language's authors value
- Error handling philosophy is the fastest way to understand a language's personality
- Reading other people's real code beats any tutorial

By day seven it stopped feeling like translation and started feeling like just... writing. That's usually the signal to keep going.
