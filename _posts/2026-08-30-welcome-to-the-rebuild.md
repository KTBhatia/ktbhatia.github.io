I tore down the old theme and rebuilt this from scratch. Same Jekyll and GitHub Pages underneath — that part isn't broken — but everything visible is new: type, layout, colors, the works.

## Why bother

The old default theme worked fine, but it never felt like *mine*. It's easy to let that slide when the actual point is to write, not to fuss over CSS. Eventually the fussing was worth doing once, properly, so it stops being a distraction later.

## What changed

- A card-based index instead of a single infinite-scroll feed
- A tighter type system: a display face for headings, a plain one for reading
- Tags instead of categories buried in a sidebar
- No dependencies beyond what GitHub Pages already builds for free

## What's next

Mostly: writing. The next few posts will cover the actual projects I've been heads-down on, not more site plumbing.
